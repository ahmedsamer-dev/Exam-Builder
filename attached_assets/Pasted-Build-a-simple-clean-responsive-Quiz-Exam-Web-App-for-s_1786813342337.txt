## Answer Logic

When the user selects an answer:

### Correct Answer

If the selected answer is correct:

* Highlight the selected answer as correct.
* Increase the score by 1.
* Disable all answer buttons.
* Show a small "Correct!" message.
* Show a **Next Question** button.

### Wrong Answer

If the selected answer is wrong:

* Highlight the selected answer as wrong.
* Immediately reveal/highlight the correct answer.
* Do NOT increase the score.
* Disable all answer buttons.
* Show a clear explanation if one is provided in the data.
* Show a **Next Question** button.

The user must always be able to clearly see which answer was correct.

## Randomization

Implement proper randomization.

Every time the quiz starts:

1. Shuffle the questions.
2. Shuffle the choices of every question.

When the user clicks Restart:

* Shuffle the questions again.
* Shuffle the choices again.
* Reset the score.
* Reset the question counter.
* Start a completely new quiz order.

Do NOT simply reverse or rotate the array. Use a proper random shuffle algorithm.
